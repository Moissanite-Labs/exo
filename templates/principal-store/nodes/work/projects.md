This is an example entity node. It shows how to keep a short, dated list of work.

**Claim.** List each active project with one line: name, purpose, where the code or files
live, and current status. Mark each line with the date it was last checked.

**Evidence.** Cite repositories, documents and the principal's own words about priorities.

**How to apply.** Before starting work, check the project's line here and its latest
timeline entry. When status changes, update this node and keep the old line in the
timeline. Split this node by project once it passes about 450 words.
