The account and permission features are adapted to the current core, rather than replacing the core with the old pilot. No old provider authentication code or desktop overlay replaces main's current implementation. Restart strips the one-session Full Access launch flag; new tabs do too.

The desktop attaches to the same core, data home and seat as the CLI. Closing its window stops its web listener and leaves the core running. A refresh must preserve session identifiers, messages, account bindings, model routes and any explicit permission scope. An idle core and no pending approvals are required before cutover. Snapshot SQLite with its backup API, retain the former launchers and app, and never restore an old database over newer work as an automatic rollback.

Local checks cover GitHub isolation, credential storage and redaction, Full Access authentication, parent-history resume, ChatGPT tool continuation, DeepSeek requests, seat binding, desktop navigation and web shutdown. Hosted checks, independent review and installation remain separate evidence. Record exact source commits, test results and installation status in the local build receipt. Do not include session contents, credentials or machine-specific paths in public receipts.

Worker configuration (#1017), shared limits (#999), orchestrator approval authority (#1004) and other unmerged feature branches are not included by this refresh. Adaptive worker selection remains a design discussion (#1016).

## Fresh-page replay repair

The first refreshed launch exposed #1172: an initial browser cursor of zero could request the entire durable event log after bootstrap filled its recent ring, stalling a long-lived core. The repair bounds this initial browser feed, applies SSE backpressure and yields between replay events. Explicit nonzero and session-filtered recovery remain durable; saved chat history still comes from its own endpoint. The regression uses a large synthetic historical head and verifies another protocol client, interrupt and cleanup.

The broad root run found two synthetic gate fixtures that used a nested argument absent from the strict bash schema. The recording fixture now explicitly declares that argument, preserving production validation and the hook-mutation isolation assertions.

D-083's architecture check remains a main-integration blocker: the credential and GitHub carries add four real inward dependencies (43 against a cap of 39). The cap is unchanged. This local alpha is not a merge-ready consolidation of those features.
