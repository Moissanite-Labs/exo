## Native acceptance

After the authorized upgrade, all 60 original session identity hashes were present and the original history counts were unchanged. The native smoke test added a 61st session. The latest user-selected DeepSeek route was restored as the runtime primary without changing the saved default, effort or speed settings.

A synthetic credential was entered through the native Credentials interface. Save and storage check succeeded, and the secure input field cleared. A real model turn then ran one bash check for the bound variable's presence and replied `CANARY_SECRET_BOUND`. The command did not print the value, access an external account or write files.

Removal through the interface disabled the binding and removed its stored value. An independent check of that exact owned Keychain item returned code 44 (absent), with cleanup complete.

The synthetic value's prefix was absent from runtime events, messages and all 11 scanned job and core log files. At native acceptance, GitHub was explicitly disabled. No real GitHub account or token was entered or tested during that acceptance pass.

The model finished before navigation back to its thread, so native restoration of an actively running animation was not verified in this pass. Automated browser cases cover that behavior. No native approval prompt appeared. The approval keyboard path is covered by disposable browser tests.

## Unexpected exit and recovery

While waiting for the preceding active turn to finish, the old core unexpectedly exited. The user confirmed they had not quit or restarted it. The last recorded tool action did not indicate a stop, restart or process signal, and no matching crash report established a cause.

Its last turn had no completion event. The open interface retained a working indication. This is an unresolved exit and stale-status finding, not a confirmed crash diagnosis.

Recovery used the reviewed candidate after checking that no replacement core or socket listener remained. The previous runtime and launcher backup remain available. The unexpected core exit is tracked in [core issue 694](https://github.com/aska-digital/exo/issues/694).
